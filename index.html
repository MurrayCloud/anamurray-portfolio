01 01 — Über mich

Mit Sorgfalt
zum guten Code

"Gute Software entsteht aus Sorgfalt, Verantwortung und dem Willen, es richtig zu machen."

Ich bin Ana Mercedes Murray Adames und werde Fachinformatikerin für Anwendungsentwicklung. Mich interessiert, wie aus einer Idee eine Anwendung wird, die anderen die Arbeit leichter macht.

Vorher habe ich eine Ausbildung zur Gesundheits- und Pflegeassistentin abgeschlossen (2023–2025). Daraus bringe ich Verantwortungsbewusstsein, sorgfältiges Dokumentieren und einen bewussten Umgang mit sensiblen Daten mit.

Seit Dezember 2025 mache ich meine Umschulung am CBW Hamburg (IHK-Abschluss 2027). Parallel habe ich mich als PCAP – Certified Associate Python Programmer und Professional Scrum Master I zertifiziert.

Für meine betriebliche Lernphase suche ich ein Praktikum vom 26.04. bis 30.11.2027 in Hamburg — in einem Team, in dem ich echten Code schreibe, Fragen stellen darf und Verantwortung übernehme.

04 Auf GitHub

Lagerverwaltung

Herausforderung: Der Kern eines ERP-Systems im Bereich Logistik: Artikel, Wareneingang, Warenausgang und Lagerwert — fehlerfrei und nachvollziehbar.

Lösung: Java-Konsolenanwendung mit Schichtenarchitektur, exakter Berechnung mit BigDecimal, Buchungsjournal, CSV-Persistenz, 18 JUnit-5-Tests und CI über GitHub Actions.

  • GitHub Actions

Auftragsverwaltung

Herausforderung: Ein sauberes Datenmodell für die Auftragsabwicklung eines Großhändlers — von Kunden bis Auftragspositionen.

Lösung: ER-Modell, normalisiertes Schema (3NF) in SQLite, zehn typische ERP-Auswertungen in SQL und ein Python-Werkzeug, das Berichte als Tabelle oder CSV für Excel ausgibt.
